# AveCove Namer

基于 LitePan 与 TMDb 的影视命名工作台：先预览、再确认，保留源语言特色。

[English](README.md) · [发布与回滚](docs/releases.md) · [更新记录](CHANGELOG.md)

## 当前版本：0.7.10

- 📦 归档代替垃圾桶：进入归档列表后可用 ↩️ 恢复。观看进度、评分和时间线保留，以前手动隐藏的剧集也能在归档中找到。

- 剧集搜索结果支持「🕒 待看」，一键收入我的剧集并加待看标签，可单独筛选；待看与收藏、在看独立保存，不自动转存或移动网盘文件。

- 全剧已看后自动隐藏我的剧集，保留时间线；单季完看不隐藏。卡片操作改图标，右侧紫色竖条显示当前集/本季集数，底部蓝色横条显示累计进度/总集数。累计进度以已看完前面的季为前提，缺失集数不估算。TMDb 链接放在点击封面后的单集弹窗内。

- **我的剧集管理**：直接填写 S/E 数字保存进度、跳转 TMDb 详情；“删除剧集”仅隐藏我的剧集中的显示，保留进度、评分和观看时间线。再次标记收藏或在看可恢复显示，不影响网盘文件。

- **完看时间线**：点 ✅ 已看，选择全剧或具体季，填写完看日期，可选评 1–5 星。各季记录互不覆盖，旧记录保留，时间线按实际完看日期排列。

- **手机查询适配**：标题、目录名独占信息行；复制、单集与源数据按钮分成两列，三种观看状态另排一行。单集及源数据操作同步适配，避免标题与目录名被挤成竖排。

- **统一观看标记**：查询、详情与收藏卡片共用 🌟 收藏、👀 在看、✅ 已看；未选中淡化，保留文字、无障碍说明和独立持久化状态。独立域名与原 `/media-tools/` 地址复用同一服务和 LitePan 配置，不迁移网盘或重置记录。

- **剧集概览**：查询结果与源数据页显示季数、每季集数、类型、剧集形式及带地区的内容分级；特别篇单列，缺失数据不冒充 0 或全年龄。首个结果轻量读取，其余按展开读取，不遍历图片或单集；我的剧集卡片同步显示概要。

- **收录通知收件箱**：本机 `notify` 命令承接 skill / Hermes 交接，持久化按版本去重，一键加入批量队列；未自动安装代理或启用无人确认改名。
- **Namer 新图标**：场记板与 N 字母组合，网页与浏览器图标统一。

- **LitePan 接入**：只展开指定目录，跨盘勾选作品，统一预览后确认改名，不依赖全盘扫描。
- **源语言命名**：父目录与子文件一致，支持 `{tmdb=...}`、季目录、电影及电影合集；歧义、重名、冲突保留人工审核。
- **TMDb 查询**：只填数字的 S/E 输入、源语言单集资料、分季图片、标题复制。
- **我的剧集**：收藏、在看、上次查询位置、已观看日期和按月时间线；原语种封面优先，其次无文字图。
- **聚焦批量操作**：批量队列醒目置顶；收录通知及 LitePan/Vesta 更新日志保留在辅助折叠区，巡影接入已移除。
- **可追溯发布**：健康接口返回版本、实际 Git 提交与运行任务数量。

旧 OpenList / Emby 兼容代码仍保留供旧安装使用，但当前网页已移除 Emby 刷新页，改名后也不会自动刷新 Emby。不同画质资源不自动删除。

## 启动与验证

需要 Python 3.10+；Node.js 22 仅用于界面测试。

```sh
python3 -m pip install -e .
python3 -m unittest discover -s tests -v
node tests/test_web_ui.mjs
avecove-namer --help
avecove-namer-web --host 127.0.0.1 --port 8787
```

服务配置参照 `deploy/` 和 `webapp.Settings.from_env` 的 `AVECOVE_*` 参数。密码、API 密钥、实际网盘路径、收藏、缓存与操作日志放在服务器私有目录，不进入 GitHub。保留现有 HTTPS 与访问方式，不额外添加反代认证。

## 改名间隔

每盘串行处理。115 初始 500 ms，每成功 50 次减少 50 ms，最低 300 ms；持久化退避可能使实际间隔更高。其他盘默认额外等待 **0 ms**，不是并发轰炸；出现限流或临时错误后仍会提高间隔，超时且结果不确定的移动不会盲目重试。

## 今后的更新流程

审核、提交后执行：

```sh
python3 scripts/publish.py --host 已配置的SSH别名 --url https://站点域名/media-tools
```

自动完成本地测试 → 同步 GitHub → 打包该提交 → 备份服务器 → 切换新版本 → 核对本机和公网提交号；本机启动失败自动退回旧版本。有任务运行时拒绝部署。GitHub Actions 同时执行多 Python 版本、界面与构建检查。

这是使用已有 SSH 的**手动一键发布**，不等于每次 push 都自动部署。没有新增或外传服务器凭据。详见 [发布与回滚](docs/releases.md)。

## 网盘 skill 如何配合

目前没有选定或安装专门的网盘 skill。本轮提供接口协作方案：skill 负责找到目录，Namer 负责 TMDb 校验、预览、明确确认与记录，不复制凭据、不越过审核、不默认删除资源。详见 [协作约定](docs/cloud-skill.md)。
