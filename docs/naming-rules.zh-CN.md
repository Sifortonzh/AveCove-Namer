# 命名规则

[English](naming-rules.md)

## 剧集

默认格式：

```text
Series.Title.2020.S01E01.1080p.WEB-DL.x265.DDP5.1.mkv
```

- 剧名与首播年份共同组成稳定身份。
- `SxxEyy` 用于准确识别季和集。
- 默认不添加单集标题。
- 已识别的画质、片源、编码和音轨信息按原顺序保留。
- 技术参数之前无法识别的装饰性文字会被去掉。

年份的取值顺序为：明确输入的 `--year`、类似 `Series Name (2020)` 的上级目录、原文件名。无法确认年份时跳过，不进行猜测。

## 电影

默认格式：

```text
Movie.Title.2024.2160p.BluRay.REMUX.DV.HDR.HEVC.TrueHD.Atmos.mkv
```

保留片名、上映年份与已经识别的技术/发布信息。

## 标题语言规则

建议采用“按作品来源自动选择主语言”的媒体库规则：

- 欧美及其他非中文作品使用英文主标题和半角括号：`Kill Bill Vol.1 (2003) {tmdb=24}`。
- 中国大陆、香港和台湾作品使用中文主标题，剧名与全角年份括号之间不留空格：`漫长的季节（2023） {tmdb=205272}`。
- 中英双语时，括号跟第一主语言走：`Kill Bill Vol.1 杀死比尔 (2003) {tmdb=24}` 或 `漫长的季节 The Long Season（2023） {tmdb=205272}`。
- 视频文件仍保留一种标准主标题，例如 `Kill.Bill.Vol.1.2003...` 或 `漫长的季节.2023.S01E01...`。

这种方式可以缩短文件名，同时让 Emby 从文件夹获得明确的 TMDB 身份。`--tmdb-id` 配合 `--title-style auto` 会让中文来源作品选中文、其他作品选英文。提供已确认 TMDB ID 后，选中的作品目录默认规范化；`--no-rename-root-folder` 是明确的退出开关。

现有季目录保持原样。`Season 01`、`Season01`、`S01`、`第一季`、`第1季` 都不会被重命名或移动，但其下的媒体文件仍会递归规范。

## 外挂字幕

字幕名称与整理后的视频完整主文件名一致，之后追加语言标记和字幕扩展名：

```text
Series.Title.2020.S01E01.1080p.WEB-DL.x265.DDP5.1.zh-CN.sup
```

原文件已有常见语言标记时会继续保留；未检测到语言时默认使用 `zh-CN`，可通过 `--subtitle-language-default` 修改。

`chs&eng`、`cht&eng` 等双语标记会继续保留。

## 明确的安全边界

- 没有可靠年份时不猜测。
- 默认不自动查询单集标题。
- 不覆盖已经存在的目标路径。
- 计划中存在冲突时禁止执行。
